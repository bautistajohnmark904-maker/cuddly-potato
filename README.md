# DCIT26 Lab 1 - Branching and Styling Workflow

## Project Description
A dynamic web application featuring external CSS styling and interactive JavaScript functionalities, managed using Git branching.

## Git Commands Used
- `git branch -M main` - Renamed default branch to main
- `git push -u origin main` - Pushed the main branch to GitHub
- `git push origin no-style` - Pushed the unstyled branch version
